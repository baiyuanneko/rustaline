rustaline 是一个零依赖、可自托管的评论系统。一个 script 标签 + 两行初始化代码， 即可为任意静态页面带来匿名评论、楼中楼回复、头像推导与垃圾评论防护。

立即试试评论 ↓ 查看接入文档
📦

零依赖单文件

原生 ES2018+，不依赖 jQuery / Vue / 任何 CDN，一个 rustaline.js 全部搞定。

🌳

楼中楼回复

沿用 Valine 经典 pid / rid 模型，回复嵌进父评论下并 @ 被回复者。

🛡️

内置反垃圾

蜜罐字段、IP 限流、可选审核先审后发，多层防护对抗机器人。

🎨

可定制主题

CSS 变量自由覆盖，深浅色自动跟随系统，移动端原生友好。

🔒

隐私优先

公共 API 永不返回 ip / mail / ua；头像由服务端推导，邮箱不落前端。

🗄️

自托管数据

评论落在你自己的 SQLite / PostgreSQL / MySQL，告别 LeanCloud 配额焦虑。

快速开始

把下面两段代码贴进你的 HTML，评论系统就上线了。

your-post.html 
<!-- ① 引入 SDK（同源部署，或填完整 URL 跨域调用）-->
<script src="/sdk/rustaline.js"></script>

<!-- ② 挂载点 + 初始化 -->
<div id="comments"></div>
<script>
  new Rustaline({
    el: '#comments',
    server: '',                          // 留空 = 同源；可填 https://api.example.com
    url: location.pathname,             // 文章标识，默认当前路径
    placeholder: '说点什么吧…',
    gravatarCdn: 'https://cravatar.cn/avatar/'
  });
</script>

想看完整后端字段定义？参考 Swagger UI 中的 /api/v1/comments 接口。
